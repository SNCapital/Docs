    Bulk streams (KB-size msgs): 0.32-0.38, mean ~0.37. Small-message streams (~200-300B): overhead-dominated, ratio >= 1.0 (S2 block minimums + per-msg file overhead beat compression). Long baseline procedure: sampler 60s jsz + du/df every 5 min for >= 6h, plot ratio(t).
