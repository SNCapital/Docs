    Critical flows¶

    • F-ingress: WS/REST → mem buffer (30–60s, cap + drop counter) → async publish md.binance.usdm.<sym>.<type> (MsgId dedup 300s, ingress_time + exchange ts + connection id).
    • F-calc (vertical slice): md.* (non-durable + PG cursor, exact-subject resume per X-001) → server-time 30m bar, ALWAYS (NULL by redesign Q-003) + quality stamp → bars.binance.usdm.*, 1 msg = 1 closed bar.
    • F-archive: md.* (durable + ack) → daily merge → S3 copy-verify-delete → local delete after verify (Q-005(b) daily bound).
    • F-trade: bars.* → wait-full-set 5 min (Q-004 builds) → 3-state gate (S-trader) → direct REST orders + user-data reconcile; stale bars ack+drop.

    Decisions index¶

    D-001 (retention/offset/wait/alerting, implemented), D-002 (S3 layout + offline backtest), D-003 (bar payload findings; Q-003 direction: nullable redesign), Q-004 (build all), Q-005 (deploy order + daily merge; fencing by order).

    Invariants index¶

    INV-001 (one bar/window, NULL — VIOLATED by engine path until Q-003 redesign), INV-002 (no silent loss — unowned on bars leg until stamp), INV-003 (disk bounded — JetStream static-done, files by daily merge).

    Critical scenarios (prose + decisions)¶

    1. Proxy burst: buffer caps (~1h sustained, ~22–30 min minute-peak), drop-oldest + counter, alert; no spill/backpressure.
    2. Archiver stalls: discard-old eats tail regardless of ack; restarts see gap → hole verdict via code probe (broker returns empty, X-001 nuance).
    3. Calc restart: exact-subject consumer from per-subject seq+1, U/u second stage; past retention → hole.
    4. Incomplete window: wait 5 min (REQUIRED, unimplemented), trade available, mark missing (REQUIRED stamp fields, undefined).
    5. Fresh infra: bootstrap ensure creates md.*+BARS idempotent before first publish (BARS subject frozen first).
    6. Two traders, one account: NO mechanism today — fencing required before cutover (Q-005).
    7. Shadow file growth: two layouts at once, unbounded today — bound + file-watching soak required (Q-005).
    8. Retire: POINT OF NO RETURN (volumes deleted + JetStream expired beyond S3) — only after soaks + migration tool.

    Ranked fragile decisions (basis class each)¶

    1. NULL/stamp payload design (Q-003) — human decision missing; engine path bakes 0.0+ffill today. Watch: first published bar validation.
    2. Single-trader fencing (Q-005) — no mechanism; monetary irreversible. Watch: two-writer probe test.
    3. File-disk bound (Q-005) — INV-003 as written covers whole host; shadow doubles files. Watch: file-watching soak.
    4. opt_start_seq × filter — REPRODUCED (X-001 2.10.29). Closed.
    5. Volumes 22–40 — measured bases + extrapolation; S2/overhead/peak unmeasured. Watch: prod-profile soak.
    6. max_bytes = 100G orientir — not sized. Watch: occupancy soak.
