    Рыночная статистика¶

    Метрики, источник которых — отдельные REST-endpoint'ы биржи, не WS-стримы. Все приходят через периодический polling (биржа обновляет с фиксированной каденцией, типично 5 минут).

    Документ описывает целевую спецификацию. Текущий парсер большинство этих метрик не собирает — соответствующая задача расширения парсера в backlog.md, пункт B4.

    Общий контекст¶

    Природа данных¶

    Все метрики этого блока — скалярные значения, одно число на (symbol|asset, timestamp). REST-endpoint биржи отдаёт текущее значение по запросу. Парсер должен поллить с фиксированной частотой и складывать в parquet.

    Целевая партиция¶

    data/market=usdm/type=market_stats/dt=YYYY-MM-DD/symbol=SYM/part-*.parquet
data/market=spot/type=market_stats/dt=YYYY-MM-DD/symbol=SYM/part-*.parquet

    (Для daily_interest_rate партиция по символу = по asset — например, symbol=BTC для borrow rate BTC.)

    Каденс¶

    Биржа обновляет эти данные c частотой 5 минут для большинства ratio-метрик; реже для daily_interest_rate (раз в час). Парсер поллит с такой же или более частой каденцией; per-bar используем last value at boundary.

    Per-bar агрегация¶

    Для всех метрик блока — last value at bar boundary с forward-fill через дыры:

    metric(B) = последнее значение метрики с timestamp ≤ B.end
          = NaN  если нет ни одного значения до B.end

    В терминах pandas: df.resample("30min").last().reindex(all_bars_idx, method="ffill").

    Edge cases¶

    • Бар до листинга символа / до запуска поллера → NaN.
    • Если биржа на эндпойнт временно отвечает 5xx и наш поллер пропустил цикл — последнее известное значение forward-filled до ближайшего обновления.

    Метрики¶

    open_interest¶

    Что измеряет. Общее число открытых perpetual-фьючерсных контрактов по символу (в USD-эквиваленте или в base coin — в спеке не фиксируется, по умолчанию в base coin).

    Источник. REST /fapi/v1/openInterest?symbol=… (только usdm).

    Каденс биржи. Real-time, биржа обновляет постоянно. Поллим с интервалом 1–5 мин.

    Что говорит. Прокси для совокупного позиционирования рынка. Рост OI + рост цены → новые лонги; рост OI + падение цены → новые шорты. Падение OI = закрытие позиций (либо liquidation, либо profit-taking).

    global_long_accounts¶

    Что измеряет. Доля счетов в глобальной выборке (Binance futures), у которых открытая позиция — long. Диапазон [0, 1].

    Источник. REST /futures/data/globalLongShortAccountRatio?symbol=… (только usdm).

    Каденс биржи. 5 минут.

    Что говорит. Sentiment-индикатор по retail. Высокое значение → большинство retail в лонгах → перекос на лонг → contrarian-сигнал (retail обычно ошибается).

    top_long_accounts¶

    Что измеряет. Доля long-счетов среди топ-20% пользователей по margin balance (то есть «крупные»).

    Источник. REST /futures/data/topLongShortAccountRatio?symbol=… (только usdm).

    Каденс биржи. 5 минут.

    Что говорит. Sentiment крупных трейдеров. Контрарность работает хуже — крупные обычно правильнее retail. Полезен в комбинации с global_long_accounts: расхождение «retail в лонгах, киты в шортах» = сильный bearish-сигнал.

    top_long_positions¶

    Что измеряет. Доля long-позиций (не счетов) среди тех же топ-20%. Учитывает размер позиции, а не только её наличие.

    Источник. REST /futures/data/topLongShortPositionRatio?symbol=… (только usdm).

    Каденс биржи. 5 минут.

    Что говорит. Более точный sentiment-сигнал чем top_long_accounts, потому что учитывает «вес» позиций. Один кит с 1000 BTC long и 99 других с маленькими short'ами — top_long_accounts ≈ 0.01, но top_long_positions отразит реальное доминирование лонгов.

    daily_interest_rate¶

    Что измеряет. Стоимость удержания шорта на споте в дневном выражении (доля). Это процентная ставка, которую биржа берёт за margin-shorting.

    Источник. Binance Margin Cross Interest Rate API (детали зависят от типа тикера; для большинства usdt-pairs это /sapi/v1/margin/...).

    Каденс биржи. Обычно 1 раз в сутки или реже. На большинстве тикеров стабилен в течение суток.

    Что говорит. Базовая стоимость sustaining-шорта. Стратегиям с шорт-плечом важно как cost карта. Высокая ставка → дорогой шорт → давление к закрытию шортов.
