    Coherent recovery cut¶

    The kernel diagnostic reproduced297 differing keys with two apparently complete bars when a later book seed represented the state after the replay cursor. Exact paired older seed replay matched. This invalidates retaining the current watermark/latest-book combination without further proof.

    Freeze books at an exact owner-applied cut S, with no await between snapshots. Publication precedes one PG transaction pairing those snapshots with scalar S and stream epoch. The current DB discards Checkpoint.seq; implementation therefore requires an explicit idempotent schema/read migration, not a new independent cursor store. Existing rows with no proven sequence remain unproven.

    Keep the durable scalar monotone at the latest committed cut S. On process restart choose an older complete paired generation R below S for fresh-engine warmup, with exact sequence/epoch per seed; applied resumes transiently from R+1. The retained valid bar authority distinguishes already published warmup rows from missing rows. Do not roll back the durable cursor. A seed must precede the first missing window start by at least liquidation10s plus admitted skew; actual cut time includes settlement10s. A prior30m generation normally has room, but equality and the inequality must be tested explicitly. No Python heap serialization is introduced. Missing/corrupt pair, retention hole or epoch reset yields an honest cold/hole state and unproven book windows.

    Live reconnect uses applied+1. Fetched is transient instrumentation; applied advances only after a complete state transition or named terminal discard; persisted is existing PG authority. Unknown partial mutation terminates the dependent path and restores from PG+MD. Dedup must not consume an event whose transition failed. New runtime healing branches are not required for every failure fixture.

    Recovery counterexample and concrete proposed cut¶

    Current snapshot can be book AFTER sequence S while PG cursor is older watermark C<S. A trade at C+1 observes future book S; intervening old diffs are skipped by u<=snapshot. Golden counts/close may match while all ob__* keys differ. New empty Engine also lacks the earlier part of the bar and W+10s liquidation history. Ten-second watermark overlap does not warm an 1800-second window. This is structural diagnosis, not executed reproduction.

    Recommend exact paired recovery generation using existing checkpoint rows/cursor, NOT heap serialization:

    • At an owner apply cut S, freeze ALL eligible symbol book snapshots and their u with identical seq=S; no await between symbol cuts, book/metrics stamp changes, or snapshot capture. Epoch ties the cut to MD identity. Never pair later book with older watermark.
    • Persist the generation only after required boundary publications. Keep latest published boundary authority B distinct from the earlier recovery seed generation R. Select checkpoint rows whose paired seq equals transient restart seed R, not latest-valid individually; keep durable published cursor S monotone (see schema correction below). R must precede the first missing bar's start by liquidation10s + admitted event skew and must provide a FULL window of replay before any newly published complete bar. A prior boundary generation is normally enough for the first bar after B; verify actual snapshot capture time including settlement. Keep enough prior generations to prove this inequality rather than assuming keep_bars=2 is universally enough.
    • Replay from R+1 once through wildcard with fresh engines and generation-R books. Suppress already-retained valid warmup outputs; reconstruct every missing output only after full warmup. All symbols share R; missing/corrupt snapshot or retained floor>R+1 is hole/cold, never mix newer snapshot with older common cursor.
    • Do not increase newest persisted resume point to applied tip merely because backlog drains. Live reconnect uses applied+1; process crash derives R from persisted S and paired checkpoint generations and uses R+1. The existing PG cursor remains sole persisted recovery authority; transient R selection beneath S must be explicitly recorded in ADR.
    • Alternative if existing schema/retention cannot preserve paired generations: cold/hole unproven windows until full new warmup. This admits a hole; it is not equality acceptance and requires owner decision. Do not silently choose it.
