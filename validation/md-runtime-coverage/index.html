    MD runtime coverage and acceptance evidence¶

    Baseline: 04e45d37 (origin/main, PR #106), inspected 2026-09-28. Scope: ADR-0003 I1–I18 from the invariant catalogue. This matrix replaces the removed replay/end_seqs suites as an inventory, not as a claim that their runtime acceptance has survived. The new runtime has one MD stream, one scalar published watermark and a completion pass. No production deployment, stream mutation, server restart or full-catalogue probe was performed for this report.

    unit means direct assertions with fake ports or a local engine; integration means the referenced test requires real disposable infrastructure. A reference proves only the stated scope. Existing PR #106 execution counts in the working plan are historical evidence, not a fresh run in this worktree.

    Runtime acceptance probes¶

    All failure injection below belongs on disposable NATS/PG infrastructure first. Server execution requires the fresh-cutover decision in P0.3; this document is not permission to delete streams, reset PG or stop running services.

    Probe Setup and measurable acceptance Evidence to retain
    Cold/full catalogue Empty disposable MD/PG; actual catalogue; start collector/calc/paper trader. Every symbol has one terminal outcome, no bars before boot completion; publish settled windows only. Repeat across settlement rollover. Exact SHA/config/catalogue count; ordered boot/drain/completion events; pending+delivered+sentinel; bar/gap count by boundary; history counts; RSS/CPU and elapsed drain/pass.
    Seeded restart Checkpoint real books+cursor after successful boundary, keep early ticks from open window, restart calc. Verify seed before read, BY_START_SEQUENCE(cursor+1), open-window parity against uninterrupted baseline. Book u, cursor, MD first/last/epoch; pre/post canonical bars; matching keys/quality; watchdog activation trace.
    Retention/reset Separate runs: retain first_seq=cursor+1 (no hole), truncate first_seq=cursor+2 (hole), recreate MD epoch, cursor>last. Exact stream/PG snapshots; verdict counts; lost-window gaps; ob stripping interval; unaffected shard; cold resume policy.
    Publish/commit/crash Fail BARS publication and PG transaction separately; cancel/kill before commit and between history/BARS publish. Restart from persisted cursor. Cursor never passes unpublished boundary; PG rollback; canonical first-wins bars; repaired gaps; no duplicate final rows; no recovery-ready event on exhaustion.
    Cold/add/remove Add symbol while a pass runs and rolls over; inject fetch/live overlap, floor duplicates, chase limit, pending cap; remove then re-add. S/F pins, floors, buffers/dedup, separate consumption sentinels, stamp merges, membership, bounded verdict skip; funding buffer cleared on removal.
    FC/reconnect/overload Real pinned nats-py, MD push FC, slow bridge/pass at peak catalogue ingress; broker reconnect and SlowConsumer callback. FC reply traffic, exact resume sequence, no hidden queue drop, pending limits vs peak × worst-pass-duration, fatal or visible skip, retried lossless bars.
    Stall/RTO/soak Block ingress/probes, then restore. Measure full-catalogue cold+seeded drain, catch-up limits and sustained 24–48h operation. RTO once per boot, stagnant-cap fatal, health diagnostic during drain, RSS headroom/trend, archive readback, complete bar/gap census, quality gates and backlog recovery.

    The existing integration overlap tests in tests/integration/test_sys_integration.py exercise direct JetStream subscribers, not run_calc_service; they are transport supporting evidence, not acceptance of the new MD runtime. No old replay code or removed test suite was restored. No production behavior changed in this work.

    Validation for this change¶

    New tests supplement the 19 PR #106 cases with focused MD contracts. They pin existing behavior and do not accompany a fix; a red/green bug-fix claim would be incorrect. Focused unit results are recorded after all edits are complete. Runtime acceptance remains open until the probes above have timestamped actual evidence.

    Final focused gate, 2026-09-28: 94 passed in 3.14s. It includes the new 16 cases, all 19 PR #106 regression cases, publication/checkpoint retry, cursor store, retained publisher, cursor/book atomicity, depth/watchdog, reconnect, bus backpressure and durable bar-history unit coverage.
